# MaxiSign User Guide

This guide provides instructions on how to use the MaxiSign application, with a focus on the PDF editing features.

## Getting Started

1. Open the MaxiSign application in your web browser.
2. You'll be presented with the home page where you can upload a PDF document.

## PDF Editor

### Loading a PDF

1. Click the "Upload PDF" button or drag and drop a PDF file onto the designated area.
2. The PDF will load in the viewer, and the toolbar will become active.

### Using the Toolbar

The toolbar provides access to all editing tools:

- **Zoom Controls**: Zoom in/out of the document
- **Grid Toggle**: Show/hide a grid for precise positioning
- **Insert Image**: Add images to your PDF
- **Save**: Save your edited PDF with all modifications
- **Undo/Redo**: Revert or reapply changes

### Adding Images to Your PDF

1. **Method 1 - Drag and Drop**:
   - Drag an image file from your computer directly onto the PDF viewer
   - Position the image where you want it to appear
   - Release to place the image

2. **Method 2 - Using the Toolbar**:
   - Click the "Insert Image" button in the toolbar
   - Select an image file from your computer
   - The image will be placed in the center of the current view

### Positioning Images

- Once an image is placed, you can see it overlaid on the PDF
- The position is preserved exactly as placed
- Use the grid feature for more precise positioning

### Saving Your Document

1. Click the "Save" button in the toolbar
2. The application will process your PDF with all placed images
3. The processed PDF will be downloaded to your computer

## Client-side Processing

MaxiSign now processes your PDFs directly in your browser for:

- **Faster Performance**: No need to upload large files to a server
- **Enhanced Privacy**: Your documents stay on your device
- **Offline Capability**: Work without an internet connection (once the app is loaded)

If the client-side processing encounters any issues, the application will automatically fall back to server-side processing without any action required from you.

## Tips and Tricks

- **Use the Grid**: Toggle the grid on for precise image placement
- **Zoom for Detail**: Use the zoom controls to work on detailed areas
- **Recent Images**: The application remembers recently used images for quick access
- **Multiple Images**: You can add multiple images to a single PDF

## Troubleshooting

### Common Issues

- **PDF Not Loading**: Make sure your PDF is not password-protected
- **Image Not Appearing**: Try a different image format (JPG or PNG recommended)
- **Save Button Disabled**: You need to have both a PDF loaded and at least one image placed

### Getting Help

If you encounter any issues not covered in this guide, please contact support at support@maxisign.com or check the FAQ section on our website.
